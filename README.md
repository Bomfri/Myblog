# Myblog - A Django Blog Project

A personal blog website built with Django as part of my journey learning web development.
The blog features a Minecraft theme and is being actively developed.

## About

I built this project to learn the basics of Django and web development.
It covers core concepts like URL routing, views, templates, and models.
This is based on an original project that I did 5 months ago, but had some issues transfering it to GitHub.

## Features (In Progress)

- Minecraft-themed front end
- Blog post pages
- Django-powered backend

## Tech Stack

- Python 3.10
- Django 5.1.3

## Getting Started

1. Clone the repository
git clone https://github.com/Bomfri/Myblog.git
2. Install dependencies
pip install django python-decouple
3. Create a .env file with my SECRET_KEY
4. Run the development server
python manage.py runserver
